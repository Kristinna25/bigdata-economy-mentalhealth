# bigdata-economy-mentalhealth

# 경제 지표와 정신건강 검색량 분석 프로젝트
 
한국의 경제 지표(소비자물가지수 CPI, 실업률)와  
구글 트렌드에서 가져온 정신건강 관련 검색어(스트레스, 우울증, 불안, 불면증, 외로움)가  
시간에 따라 어떤 식으로 변화하는지 분석해 보았다.


# 프로젝트 목적
경제 상태가 안 좋으면 사람들이 정신적으로도 힘들어지지 않을까 하는 생각에서  
경제 지표 변화와 정신건강 검색량 사이에 관계가 있는지 확인하고 싶었다.  
파이썬과 Colab을 사용해서 데이터 전처리, 시각화, 그리고 ARIMA 예측까지 진행했다.

# 사용한 데이터 
- **economy_activity.csv** → 실업률 데이터가 포함됨  
- **cpi.csv** → 월별 CPI(물가) 데이터  
- **mental_trends.csv** → 구글 트렌드 정신건강 키워드 검색량  

# 데이터 전처리 과정

### 1. 실업률
- "실업률"이 포함된 행만 추출  
- wide 형식 → long 형식으로 변환  
- 날짜를 'datetime'으로 정리  
- 결측치는 평균값으로 채움  

### 2. CPI
- "소비자물가지수"가 있는 행 선택  
- 'melt'로 long 형식 변환  
- 날짜·수치 정리 후 NaN은 평균값으로 처리  

### 3. 구글 트렌드
- 상단 메타데이터 2줄 제거   
- '<1'은 그냥 '1'로 바꿈  
- 결측값은 컬럼 평균으로 채움  

사용한 5개 keyword: 스트레스, 우울증, 불안, 불면증, 외로움

# 데이터 병합
날짜('date') 기준으로 세 데이터를 모두 병합했다.  
최종 데이터에는 다음 컬럼이 포함된다

- CPI  
- 실업률  
- 스트레스 / 우울증 / 불안 / 불면증 / 외로움  

# 시각화 

# 경제 지표 시계열 그래프
CPI와 실업률이 연도별로 어떻게 변하는지 보여준다.  
CPI는 꾸준히 상승하고, 실업률은 낮은 범위에서 조금씩 변동하는 모습이 나왔다.

# 정신건강 키워드 시계열 그래프
각 키워드의 월별 검색량 변화 그래프
특정 시기에 검색량이 확 올라가는 경우를 쉽게 볼 수 있다.

# 상관계수 히트맵
경제 지표와 정신건강 검색량 사이에  
어떤 변수끼리 관계가 있는지 색으로 확인할 수 있다.

# Plotly Animation
연도별 평균값을 이용한 버블 그래프이다.  
버블 크기는 CPI이고, y축은 정신건강 검색량  
연도별 분위기 변화를 직관적으로 볼 수 있다.

# ARIMA 예측 결과
정신건강 키워드(5개)에 ARIMA 모델을 적용해서 다음 구간을 예측했다.

예측 방법:
- 데이터 80%는 학습용, 20%는 테스트용  
- 'ndiffs()'로 차분 횟수 자동 설정  
- 'auto_arima()'로 (p, d, q) 자동 탐색  
- RMSE 계산해서 모델 성능 확인  

그래프에서는:
- 연한 선 → 학습 데이터  
- 점선 → 테스트 데이터  
- 굵은 선 → 예측값
